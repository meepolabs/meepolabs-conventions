# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| v1.x | Yes |

Fixes ship as a new v1.x release. Callers pin the action by commit SHA
and the Renovate preset by tag, so adopting a fix means moving the pin.

## Reporting a vulnerability

Email developers@meepolabs.com. Please do not open a public issue for a
security problem.

Include what you found, the affected version or commit, and steps to
reproduce. We will acknowledge the report and keep you updated until it
is resolved.
